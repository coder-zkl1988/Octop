## 已落地的边界

插件沿用 harness 支持的 `kind: tool`、`setup(ctx)` 和 `ui.entry`，另由 Octop 读取 `plugin.yaml` 的 `app.sdk: 1`。这是一层宿主扩展，不修改已发布的 harness PluginContext，也不声称 harness 已支持 `kind: domain` 或完整 SDK v2。

- 插件包：`src/octop/infra/agents/plugins/bundled/xhs-ops/`，业务代码、动态页面、manifest、图标与 MIT 来源的 phone-skills v66 bundle 一起安装。
- 宿主：`infra/plugin_apps/`，负责身份、许可、作用域存储、CAS、定时触发、手机适配和证据读取。
- HTTP 接口包括通用插件入口 `GET /api/plugin-apps`、`GET /api/plugin-apps/{id}/models`、`GET /api/plugin-apps/{id}/snapshot`、`POST /api/plugin-apps/{id}/commands`、`GET /api/plugin-apps/{id}/evidence/{run_id}`，以及迁移兼容的类型化资源 facade：项目画像/人设、账号资料草稿、评论、运行、日常计划建议、设备绑定、接管身份/方案和设备转移入口。所有 facade 仍复用同一宿主许可证、作用域和 CAS 状态机。
- 页面：`/apps` 列表、`/apps/:pluginId` 动态页面。页面通过 `host.registerPage()` 注册，工具结果仍通过现有 renderer 注册。
- 企业授权：tabby-enterprise 提供平台发放/试用/撤销、成员功能分配、SQLite/PostgreSQL 持久化及审计。付款或试用审批的依据由平台管理员填写，本轮没有支付渠道、自动扣款或支付回调。

## 授权和生命周期

有效功能 = 未过期/未撤销的租户许可 ∩ 当前成员分配。tenant/member 身份来自企业会话；不能由请求体设置。安装、全局 enabled、按专家开关、成员功能授权分别独立，本地 admin 不绕过付费许可。

每个 HTTP command 进入插件前按 manifest.commands 验权；插件内再次检查具体操作。工具调用和 scheduler 也检查许可。对正在执行的手机任务，每十秒刷新授权，撤销或后端不可用时停止，停止未确认保留 unknown。只读历史不等于可以发新任务；停止、人工核验和对账是单独的安全收口命令。

读取按 manifest.read_scopes 过滤集合；analytics-only 不拿到草稿/图片/评论/账号身份。私有截图需 JWT，通过 `host.requestBlob` 读取，不能把 JWT 放进图片 URL。

业务文档存于既有 settings 表，key 包含 plugin/tenant/member/local-user 的不可歧义 hash；并发写采用整文档 CAS。账号/设备配额另以租户作用域 CAS 预留。当前适合预览的小规模本机工作流，不能把它描述为已完成大规模任务表、跨设备租约或云端业务同步。

任务预检生成五分钟确认摘要，绑定账号、草稿内容/版本和许可版本。运行保存稳定 task_id 和 operation_key；queued→preparing、派发前状态均由 CAS 检查。取消后不能执行；unknown、stopped_unverified 或已经人工核验的相同公开动作不能仅换一个幂等键就重发。

手机模型marker和截图不构成确定性平台验证。发布、评论与资料修改仍需独立回读和人工确认。日常运营分别记录“执行回执”和“平台核验”：有效绑定任务、逐篇回执与控制器实测耗时只支持手机执行完成；互动仍标pending，浏览/停留标not_verifiable，不把它们汇总为平台已核验动作。平台核验缺失不会触发重发副作用。

历史读取权限已改为企业控制面明确返回的 read_features：有效许可按当前执行功能过滤；过期/撤销后按最后有效购买范围与当前成员分配的交集过滤，inactive为空。缩减为analytics-only再撤销，不会重新暴露项目、草稿、完整运营记录、截图和素材；缺少该字段的旧authority在只读路径拒绝访问。SQLite与PostgreSQL的授权更新在事务内保留最近有效购买范围，过期/撤销请求体不能扩大它；停用成员或租户同时清空读能力。桌面宿主的集合/记录/证据过滤与控制面对应授权增量均已通过独立只读复核，未发现P1/P2；控制面139项通过，隔离PostgreSQL的降级/成员交集/撤销/过期/CAS/RLS用例通过，测试数据库及非超级用户角色均已清理。
